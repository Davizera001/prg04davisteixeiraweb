# Site de Psicologia

## Descrição

Este projeto consiste no desenvolvimento de um site profissional para uma psicóloga, com o objetivo de apresentar informações sobre seu trabalho, áreas de atuação, serviços oferecidos e formas de contato.

O projeto está sendo desenvolvido como atividade da disciplina **PRG04 - Programação para Web**, utilizando HTML e posteriormente outras tecnologias de desenvolvimento web.

## Objetivo

Desenvolver um site organizado, intuitivo e responsivo que permita aos visitantes conhecer o trabalho da profissional, suas áreas de atuação, serviços oferecidos e encontrar formas de entrar em contato.

## Estrutura do projeto

```text
/
├── README.md                         # Documentação e descrição do projeto
│
└── infraestructure/                  # Diretório principal dos arquivos do site
    │
    ├── assets/                       # Arquivos e recursos utilizados pelo site
    │   ├── css/                      # Arquivos de estilização (CSS)
    │   ├── images/                   # Imagens utilizadas no site
    │   └── icons/                    # Ícones e favicon
    │
    └── pages/                        # Páginas HTML do site
        └── index.html                # Página principal do site
```

## Organização dos diretórios

### `README.md`

Arquivo responsável pela documentação do projeto, contendo informações sobre sua finalidade, objetivos e organização dos arquivos.

### `infraestructure/`

Diretório principal onde estão organizados os arquivos necessários para o funcionamento e desenvolvimento do site.

### `infraestructure/assets/`

Diretório destinado aos recursos utilizados pelas páginas do site.

* **`css/`** → contém os arquivos responsáveis pela estilização das páginas.
* **`images/`** → contém as imagens utilizadas no site.
* **`icons/`** → contém ícones, favicon e outros elementos gráficos.

### `infraestructure/pages/`

Diretório destinado às páginas HTML do projeto.

* **`index.html`** → página principal do site, sendo o ponto inicial da navegação.

## Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript *(posteriormente)*

## Desenvolvimento

O projeto está sendo desenvolvido de forma gradual, inicialmente com a criação da estrutura HTML e organização dos arquivos. Posteriormente serão adicionados recursos de estilização, interatividade e outras funcionalidades necessárias para o site.
