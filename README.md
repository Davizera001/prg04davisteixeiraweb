# Site de Psicologia

## Descrição

Este projeto consiste no desenvolvimento de um site profissional
para uma psicóloga, com o objetivo de apresentar informações
sobre seu trabalho, áreas de atuação, serviços oferecidos e
formas de contato.

O projeto está sendo desenvolvido como atividade da disciplina
PRG04 - Programação para Web, utilizando HTML e posteriormente
outras tecnologias de desenvolvimento web.

## Objetivo

Desenvolver um site organizado e intuitivo que permita
aos visitantes conhecer o trabalho da profissional e encontrar
formas de entrar em contato.
